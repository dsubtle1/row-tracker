{# Leaflet, loaded from unpkg with Subresource Integrity so the fetched bytes are cryptographically verified against what's expected — a compromised or tampered CDN response would simply fail to execute. Falls back to the local copy in static/{js,css}/vendor/ if the CDN is unreachable (offline/air-gapped homelab, CDN outage, blocked network) — keeps "no external dependencies required" true for the app shell itself. Map *tiles* are a separate story (see journey-map.js): those come from OpenStreetMap/CARTO over the network on every view, same as any other real map — there's no offline tile cache here. To bump the pinned version: change the version below, then regenerate both integrity hashes and the local fallback from the same URLs so they stay byte-identical: V=X.Y.Z curl -fsSL "https://unpkg.com/leaflet@$V/dist/leaflet.js" -o static/js/vendor/leaflet.js curl -fsSL "https://unpkg.com/leaflet@$V/dist/leaflet.css" -o static/css/vendor/leaflet.css openssl dgst -sha384 -binary static/js/vendor/leaflet.js | openssl base64 -A openssl dgst -sha384 -binary static/css/vendor/leaflet.css | openssl base64 -A #}
