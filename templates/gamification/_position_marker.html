{# Current-position marker + "You are here" label, shared by all 4 journey maps. Two variants for the two label orientations the routes use: - _side : left/right offset — Rhine (vertical) and Holland (loop). marker needs x, y, right (bool), rank (int). - _above : above/below offset — Trans-Canada and Route 66 (horizontal). marker needs x, y, label_above (bool), label_rank (int). rank/label_rank (from the layout helpers in gamification.py) pushes the label further out when the nearest waypoint label is close by. #} {% macro position_marker_side(marker, r=10) %} {% set dx = 16 + marker.rank * 16 %} {% set dy = 20 + marker.rank * 16 %} {% set label_x = marker.x + (dx if marker.right else -dx) %} {% set label_y = marker.y - dy %} You are here {% endmacro %} {% macro position_marker_above(marker, r=10) %} {% set dy = 20 + marker.label_rank * 24 %} {% set label_y = marker.y - dy if marker.label_above else marker.y + dy %} You are here {% endmacro %}
