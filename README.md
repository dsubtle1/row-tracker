A personal, self-hosted web application for Concept2 rowers. Syncs automatically with the Concept2 Logbook API to track workouts, calculate personal bests, and visualize training load over time. Includes a rule-based workout of the day generator, a gamification layer with badges and season challenges, a you-vs-past-you comparison board, and virtual journey maps (Rhine River, Holland Tour, Trans-Canada Highway). Built with Flask, SQLite, and Docker.
